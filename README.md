# OpenWorldGame — GTA-like открытый мир на Unity 6000

Открытый мир ~1км × 1км с городом, горами, трафиком и геймплеем в духе GTA: деньги, работы, оружие, NPC и куча способов заработка.

![Unity](https://img.shields.io/badge/Unity-6000.5+-black) ![C#](https://img.shields.io/badge/C%23-9-green)

## Что уже играбельно

### Мир
- **Город 998м × 998м** — 12×12 кварталов (68м + дороги 14м), здания с оконными текстурами (процедурный `MaterialLibrary`), дороги с белой разметкой, парки с деревьями, фонари. Генерация по сиду — детерминированная.
- **Горы** — скалистое кольцо вокруг города (коробки + сферы-пики), закрывает горизонт и не даёт выпасть.
- **Небо** — процедурное `Skybox/Procedural` (`_SkyTint 0.5,0.5,0.6`, `_GroundColor`, `_AtmosphereThickness 1.05`, `_Exposure 1.25`) + туман `Exponential 0.0022` и даль камеры `2000м`.

### Геймплей

| Фича | Как работает |
|---|---|
| **Деньги** | `PlayerWallet` — `$250` на старте, сохраняется в `PlayerPrefs`. HUD по центру сверху. |
| **Табло работ** | 3 точки в центре города (жёлтый/синий/зелёный кубы 2м): **Такси, Курьер, Сбор**. Подойди → `E` взять задание. Маркер-маяк крутится над целью. |
| **Такси** | Отвези пассажира до случайной дороги — `$120-200` |
| **Курьер** | Доставь посылку к подъезду квартала — `$90-150` |
| **Сбор** | Забери груз на дороге — `$60-100` |
| **Монетки** | 36 золотых цилиндров по обочинам — `$12-40` каждая, крутятся и подпрыгивают. |
| **Банкоматы** | 5 зелёных ящиков у зданий — `E` ограбить на `$250`, кулдаун 45с. |
| **Сущности** | `Pedestrian` — 28 NPC бродят по тротуарам, убегают, при смерти дропают `$30` |
| **Оружие** | Пистолет на игроке (пешком): **ЛКМ** — выстрел рейкастом 120м, урон 35, отдача `Rigidbody`, **R** — перезарядка `18/18`, `1.1с` |

**5 способов зарабатывать:** работа (3 вида), монетки, банкоматы, дроп с NPC, + вождение/исследование.

### Управление

| Клавиша | Действие |
|---|---|
| WASD | Ходьба / руль и газ |
| Shift | Бег |
| Space | Прыжок / ручник |
| E | Сесть/выйти из машины, взять работу, банкомат |
| ЛКМ | Стрельба (только пешком) |
| R | Перезарядка |
| Мышь | Камера (клик — вернуть курсор) |
| H | Подсказки |
| Esc | Курсору |

### Машины и трафик
- Физика: `Rigidbody 1500кг` + 4 `WheelCollider` (пружина 35k, демпфер 4.5k), задний привод, `max 140 км/ч`, диски крутятся с полоской.
- Парковка: 6 машин у обочины (вне полосы трафика)
- Трафик: 14 kinematic машин с ИИ — едут по правой полосе `2.6м`, луч `6м` тормозит перед препятствием, поворачивают на перекрёстках 60% прямо.

### UI
- Мини-карта 220×220 справа сверху (`RenderTexture 256`, орто 170м, зелёная точка — ты)
- Деньги по центру сверху, задание (описание + $ + дистанция) снизу по центру, патроны/скорость справа снизу, подсказки по центру.

## Быстрый старт

1. **Unity Hub** → установи **Unity 6000.5+ LTS** (шаблон любой) — https://unity.com/download
2. В Hub → **Add project from disk** → выбери папку `openworldgame` (не `My project/`)
3. Дождись компиляции — демо-сцена **соберётся сама** при первом открытии. Если нет — **OpenWorld → Собрать демо-сцену**
4. Жми **Play**

> Проект совместим с **2022.3 LTS** и **6000+**. Версия в `ProjectSettings/ProjectVersion.txt` — `6000.5.10f1`.

```

├── Player/CarInteraction.cs       — E в машину
├── Vehicle/{CarController,CarFactory,CarSpawner,TrafficCar,TrafficSpawner}.cs
├── CameraRig/ThirdPersonCamera.cs — орбита + автодовод за машиной
├── Economy/{PlayerWallet,MoneyPickup}.cs
├── Jobs/{JobManager,JobMarker,JobGiver}.cs
├── Entities/{Entity,Pedestrian}.cs
├── Weapon/Pistol.cs
├── World/ATM.cs
├── UI/{GameManager,Minimap}.cs
└── Editor/SceneBuilder.cs         — авто-сборка сцены + все спавнеры
```
